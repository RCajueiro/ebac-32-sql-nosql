# Atividade do Módulo 32: Bancos de Dados SQL e NoSQL

Repositório criado para a atividade prática do **Módulo 32** do curso da EBAC, com foco na comparação e aplicação de bancos de dados **SQL** e **NoSQL**.

## 📚 Objetivo

Este projeto tem como objetivo consolidar o conhecimento sobre as diferenças fundamentais, casos de uso e sintaxe entre os paradigmas de banco de dados relacionais (SQL) e não relacionais (NoSQL) através de exercícios práticos.

## 📁 Estrutura do Repositório

A atividade está organizada em duas pastas principais, cada uma contendo os exercícios ou exemplos correspondentes:

```
ebac-32-sql-nosql/
├── SQL/           # Contém arquivos relacionados a bancos de dados SQL (ex: MySQL, PostgreSQL).
├── NoSQL/         # Contém arquivos relacionados a bancos de dados NoSQL (ex: MongoDB, Redis).
```
